# Sandcage panel

The web panel for Sandcage: start a run, watch every action hit the gate, answer
approvals, stop, rewind, release a withheld patch, read the report. Next.js (App Router),
React, TypeScript strict, Tailwind. Three runtime dependencies (next, react, react-dom),
everything else is dev-only and pinned exactly.

Design: `Design/` in the project vault (Ember on Graphite). Event types: `../contract/`
(generated by the backend, never hand-written here). Wording: `lib/copy.ts`.

## Run it (no backend, no tokens)

```
cd frontend
npm ci
npm run mock                      # mock API on http://127.0.0.1:8001 (scripted runs)
npm run dev                       # panel on http://127.0.0.1:3000
```

Use `127.0.0.1`, not `localhost` (Chrome's oversized localhost cookies cause HTTP 431).
Mock options (env): `MOCK_SPEED` (1 = readable, 0.02 = fast), `MOCK_CODE` (turn on the
access code), `MOCK_RUNS_PER_DAY`, `MOCK_SEED=1` (a few finished runs), `MOCK_ORIGINS`.
The mock serves the endpoint shapes of `Specs/API.md` with events from the contract.
Scripted scenarios: `demo` (replays `contract/samples/demo-run.jsonl` with live approvals),
`sneaky_urllib`, `skip_test`, `rollback`, `clarify`. Everything it returns is mock data;
the Bench numbers it can return are labelled test data.

Test controls (mock only): `POST /__mock/inject {target, mode: error|empty|slow|off}`,
`/__mock/pause`, `/__mock/bench {kind: scripted|real|none}`, `/__mock/seed`, `/__mock/reset`.

## Point it at the real API

Change one value and rebuild: `NEXT_PUBLIC_API_URL=/api` (behind Caddy) or the API's URL.
The only module that talks to the API is `lib/api.ts` (plus `lib/stream.ts` for events).
What the real API must match is in `CONTRACT-REQUESTS.md`.

## Checks

```
npm run check          # lint, typecheck, unit tests, production build   (make panel-check at the repo root)
npm run e2e            # Playwright against the mock: one worker, no retries
npm run screens        # writes screens/*.png (desktop 1440 and phone 390)
npm run wording:verify -- "<vault>/Projects/Sandcage/Design/PAGES.md"
```

## How it is built

- The event log is the only state. `lib/derive.ts` derives phases, the pending approval,
  blast radius, outcome and the rest with pure functions; a reload or a resume just
  rebuilds the log.
- Events are read with `fetch` and a small SSE parser (`lib/sse.ts`, `lib/stream.ts`), not
  `EventSource`: resume with `Last-Event-ID`, bounded retries, 45 s idle = dead.
- One banner component (`components/decision-banner.tsx`) renders every approval kind
  from the contract's `Approval` record. A test fails if a kind in the contract has no
  fixture.
- Honest data: blocked sentences come from the backend; tokens show only when reported;
  cost is never shown; Bench numbers show only for a real model; a withheld patch reads
  "Withheld", never "Delivered".
